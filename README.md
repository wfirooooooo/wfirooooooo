## 🌟 Featured Projects

### 🔍 [Novbot](https://github.com/wfirooooooo/novbot) — Intelligent System Inspection Robot
Pure-Rust lightweight alternative to Zabbix/Prometheus for "fast check + instant alert" scenarios.
- **One binary end to end**: 4 infrastructure checks + 8 middleware checks (MySQL/PostgreSQL/Redis/ES/Nginx/MongoDB/Kafka/RabbitMQ) → alert engine → webhook/SMTP/log dispatch
- Built an async `Checker` trait with per-check hard timeouts and failure isolation; compile-time plugin registry; Axum server with SQLite persistence & REST API
- **EE edition**: distributed multi-Agent (Edge→Region gRPC), NATS JetStream, multi-tenant RBAC, TimescaleDB, 127-item compliance engine
- `Rust` `Tokio` `Axum` `sqlx` `async-trait`
